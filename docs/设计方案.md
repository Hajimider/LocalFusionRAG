# 法律辅助混合 RAG 设计方案

## 1. 目标

面向中国大陆中文法律资料，帮助用户从本地法条和已授权公开判例中快速定位依据、区分现行与历史版本，并辅助拆解案件事实和争议焦点。系统不自动给出律师意见，不保证资料实时有效。

## 2. 数据与元数据

支持 PDF、Markdown、TXT。Markdown/TXT 可在文件头使用简单 YAML front matter：`doc_type`（`law`/`case`）、`validity`（`current`/`historical`/`unknown`）、`jurisdiction`、`effective_date`、`expiry_date`、`court`、`case_number`、`judgment_date`、`source_url`。未标注字段保持 `unknown` 或空值，禁止由模型推断。

## 3. 检索链路

文档解析后按重叠窗口切分，使用 BGE 生成向量并写入 FAISS，同时构建中文 BM25 倒排检索。两路结果使用 RRF 融合，再按需调用 CrossEncoder；模型不可用时回退到 BGE 向量重排序，继续失败则保留 RRF 顺序。检索前可按资料类型和效力状态过滤候选文档。

## 4. 意图与生成

规则优先识别现行法条、历史法条、判例检索、案件分析、法律对比、时间线和普通问答，低置信度时可调用模型分类。法律 Prompt 强制区分法条与判例，要求引用法院、案号、日期等元数据，资料不足时拒答，并附法律免责声明。

## 5. 服务接口

FastAPI 提供健康检查、文档上传、索引构建和流式问答接口。网页支持混合/向量/BM25 检索、资料类型、效力状态、Top-K、查询改写和重排序开关；来源展示与回答分离，便于复核。

## 6. 合规边界

资料由用户从国家法律法规数据库、人民法院案例库等官方或获授权渠道下载后导入。项目不批量抓取受限网站，不把未授权案例或个人敏感信息写入仓库；正式使用前仍需回到官方来源核对现行状态。
