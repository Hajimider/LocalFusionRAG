# RAG 基础

## 什么是 RAG

RAG 是检索增强生成。系统先把外部文档切分并转换成向量，用户提问时从向量索引中找到语义相关的片段，再把片段放入提示词交给语言模型生成答案。RAG 的优势是知识可以通过更新文档和索引进行维护，不必重新训练语言模型。

## 一个标准流程

标准 RAG 通常包含文档加载、文本切分、向量化、索引保存、问题向量化、相似度检索、提示词组装和答案生成。检索结果应保留来源信息，回答中显示引用，方便用户核对依据。

## RAG 与微调的区别

RAG 适合补充经常变化的事实、企业文档和项目资料。微调适合改变模型的输出格式、表达风格或特定任务行为。二者可以组合，但不应把微调当作更新知识库的首选方式。

## 无答案处理

如果检索结果与问题的相关度过低，系统不应强行生成看似确定的答案。更稳妥的做法是明确告诉用户知识库中没有足够信息，并建议补充资料或换一种问法。
