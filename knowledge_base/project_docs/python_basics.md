# Python 基础

## 列表与元组

列表是可变序列，可以在创建后增加、删除或修改元素，通常使用方括号表示。元组是不可变序列，通常使用圆括号表示。需要频繁修改数据时适合使用列表；数据不应被修改，或者希望表达固定结构时，可以使用元组。

## 异常处理

Python 使用 `try`、`except`、`else` 和 `finally` 组织异常处理。`try` 放置可能出错的代码，`except` 捕获指定异常，`finally` 中的代码通常无论是否发生异常都会执行。建议捕获具体异常类型，不要在业务代码中直接捕获所有异常后静默忽略。

## 虚拟环境

虚拟环境可以隔离不同项目的 Python 依赖。创建环境后，应在项目的依赖文件中记录包名和版本范围，并在新环境中重新安装依赖，避免直接依赖某台电脑上的全局包。
