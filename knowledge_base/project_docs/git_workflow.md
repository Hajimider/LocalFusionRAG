# Git 常用工作流

## 提交代码

一次常见的 Git 提交流程是：先使用 `git status` 查看工作区状态，再使用 `git add` 将目标文件放入暂存区，接着使用 `git diff --staged` 检查暂存内容，最后使用 `git commit -m` 创建提交。提交信息应该说明这次修改的目的。

## 分支开发

功能开发通常在独立分支完成。创建分支前先同步主分支，完成修改后运行测试，再提交并发起合并请求。合并前应检查冲突、测试结果和变更范围，避免把临时文件或本地配置提交到仓库。

## 忽略文件

`.gitignore` 用来声明不应进入版本库的文件，例如虚拟环境目录、模型权重、缓存、日志和包含密钥的本地配置。忽略规则只能阻止尚未被跟踪的文件进入暂存区，已经被跟踪的文件需要另外处理。
